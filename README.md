# Visualization_of_Graph_Algorithms_for_Vector_Search
Данное приложение содержит руководство по развертыванию комплекса визуализационных симуляторов на локальной рабочей станции с использованием среды разработки Visual Studio Code (VS Code).

Шаг 1. Подготовка среды
	Необходимо настроить и подготовить окружение, в которой будут запускаться все алгоритмы, в нашем случае Visual Studio Code, создадим папку с нашими скриптами и затем установим последнюю версию Python (если ее нет):
1)	Создайте папку и добавьте в нее все скрипты (NSG.py, SPANN.py, HNSW.py, DiskANN.py и CARGA.py).
2)	Откройте эту папку через VS Code, перейдя в раздел File > Open Folder
4)	Откройте терминал через раздел Terminal > New Terminal или при помощи команды Ctrl + ~
5)	Выполните установку новой версии Python при помощи команды в терминале (для избежания ошибок рекомендуется выполнить команду без включенного VPN):
 
winget install --id Python.Python.3.14 --exact --source winget

6)	После установки выполните команду Ctrl + Shift + P в VS Code и откройте раздел Python: Select Interpreter
7)	Выберете новую установленную версию Python

  Продолжим подготовку нашей среды для запуска всех скриптов, а именно установим все зависимости для этого:
1)	Установим нужные зависимости. В терминале выполните следующую команду:

pip install streamlit numpy scikit-learn plotly networkx matplotlib scipy

Шаг 2: Запуск симуляторов
  Все скрипты представляют собой интерактивные локальные веб-приложения, созданные при помощи фреймворка Streamlit. Попытки запуска через привычную команду Run приведёт к ошибке. Чтобы успешно запустить скрипты:
1)	Откройте терминал через раздел Terminal > New Terminal или при помощи команды Ctrl + ~ в папке со скриптами
2)	Введите streamlit run и затем точное название нужной программы, например:

streamlit run HNSW.py

3)	После этого программа автоматически перенесет вас в браузер по адресу http://localhost:8501
4)	Чтобы завершить работу программы, необходимо закрыть страницу с локальным веб-приложением и в VS Code в терминале выполнить комбинацию клавиш Ctrl + C , затем можно будет запускать любую из других программ по тому же принципу (пункт 2)
