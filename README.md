# Visualization_of_Graph_Algorithms_for_Vector_Search
Данное приложение содержит исчерпывающее руководство по развертыванию комплекса визуализационных симуляторов на локальной рабочей станции с использованием среды разработки Visual Studio Code (VS Code).

Шаг 1. Подготовка системного окружения 
Для корректной работы всех подпрограмм на рабочем компьютере должен быть установлен интерпретатор языка Python версии 3.8 или новее. Убедиться в корректности установки можно, открыв встроенный терминал в VS Code и выполнив команду:

python -version

Или, для систем на базе macOS/Linux:

python3 -version

При необходимости, установите более новую версию интерпретатора языка Python.

Шаг 2. Загрузка исходных файлов 
Пользователю необходимо скачать предоставленные Python-скрипты (CARGA.py, NSG.py, DiskANN.py, SPANN.py, HNSW.py). Рекомендуется поместить все загруженные файлы в единую директорию (папку) на локальном диске.

Шаг 3. Установка программных зависимостей
Для работы математического аппарата и средств визуализации требуется загрузить сторонние библиотеки. Находясь в активированном окружении, выполните команду:

pip install streamlit numpy scipy matplotlib plotly scikit-learn network

Процесс загрузки и установки пакетов может занять несколько минут в зависимости от скорости интернет-соединения.

Шаг 4. Запуск симуляторов
Запуск осуществляется с помощью командного интерфейса фреймворка Streamlit. Для инициализации конкретного алгоритма (например, DiskANN) необходимо ввести в терминале:

streamlit run DiskANN.py

После выполнения данной команды Streamlit автоматически запустит локальный веб-сервер и откроет новую вкладку в системном веб-браузере по умолчанию. Типичный адрес интерфейса — http://localhost:8501.

Шаг 5. Взаимодействие с интерфейсом После открытия приложения в браузере пользователь получает доступ к графическому интерфейсу:
1.	В левой части экрана расположена боковая панель, где находятся ползунки управления гиперпараметрами (например, количество узлов, максимальная степень, параметры alpha или epsilon).
2.	Любое изменение позиции ползунка автоматически инициирует пересчет графовой или кластерной структуры и обновление графического полотна в правой части экрана.
3.	Кнопки (например, «Запустить жадный поиск» или «Generate Query and Route») генерируют новый случайный вектор запроса, активируют алгоритм обхода и накладывают пройденный маршрут поверх существующего графа.
4.	Для завершения работы сервера достаточно закрыть вкладку браузера и нажать комбинацию клавиш Ctrl+C в терминале VS Code. Для перехода к изучению другого алгоритма повторите команду запуска (Шаг 4), указав соответствующее имя файла.
